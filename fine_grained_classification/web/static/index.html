🐱🐕 细粒度猫狗品种分类系统

基于 CLIP + 动态提示词优化的细粒度分类研究演示

🔬 研究亮点

本系统展示了 DynamicPromptTrainer 方法，通过可学习难度加权和图像条件化动态提示词， 在 Oxford-IIIT Pets 37类细粒度分类任务上达到 89.8% 的准确率（16-shot）， 超越 CoOp (89.3%) 和 CoCoOp (89.6%)。

📸 上传图片进行分类

🤖 动态提示词模式

本系统使用 AdaptivePromptLearner 自动生成图片专属的动态提示词，无需手动输入。

1
输入图片 → CLIP 视觉编码器
→
2
类别自适应因子调整
→
3
SoftPromptAdapter 生成偏移
→
4
动态提示词 → 文本编码器

提示词会根据图片内容自动调整，每张图片的提示词都是独特的。
