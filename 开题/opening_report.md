## 基于自适应提示词优化的细粒度猫狗分类研究

### 开 题 报 告

---

## 一、综述本课题国内外研究动态，说明选题的依据和意义

### 1.1 细粒度图像分类的研究现状与意义

细粒度图像分类（Fine-grained Image Classification, FGIC）是计算机视觉领域的一个关键挑战。相比于普通图像分类任务要求模型区分不同的高级概念（如"狗"与"猫"），细粒度分类需要在同一类别内识别细微的视觉差异，如识别具体的狗品种、猫品种或特定的鸟类物种。随着深度学习在图像分类领域的广泛应用，以CNN为代表的卷积神经网络在ImageNet等大规模数据集上取得了显著进展。然而，细粒度猫狗分类因品种间特征细微、易受拍摄环境、光照、姿态等因素干扰，仍是极具挑战性的任务。当前基于单一模态（如仅使用图像像素）的深度学习方法虽然能达到80-95%的准确率，但在处理视觉相似度高的品种（如英国猎犬与比格犬）时仍存在明显瓶颈，且泛化能力有限。

**研究意义**：（1）学术意义：细粒度猫狗分类作为一个具有代表性的细粒度分类问题，是验证新方法有效性的重要基准任务，研究成果可推广到其他细粒度分类领域；（2）应用价值：精准的宠物品种识别在宠物医疗、宠物保险、流浪动物救助、宠物社交平台等领域具有重要应用前景；（3）理论贡献：探索如何在多模态框架中精准捕捉品种级别的细粒度差异，可为细粒度视觉识别提供新的技术路线。

### 1.2 视觉语言预训练模型与提示工程的发展

近年来，以CLIP（Contrastive Language-Image Pre-training）为代表的视觉语言预训练模型（Vision-Language Pre-trained Models, VLP）在多个视觉和跨模态任务上展现了强大的零样本和少样本迁移能力。CLIP通过在40亿互联网图像-文本对上进行对比学习，学习了统一的视觉-语义嵌入空间，使其能够直接对新类别进行推理，无需重新训练。这一范式的核心优势在于：它突破了传统监督学习需要大量标注数据的瓶颈，并展现出更强的泛化能力和鲁棒性。

然而，尽管VLP模型性能强大，其在下游任务上的有效应用面临"提示工程"的瓶颈。提示工程（Prompt Engineering）是指为预训练模型设计和优化自然语言输入（提示词），以引导模型进行语义推理和特征识别的技术。传统的手工设计提示词（如直接使用"a photo of a dog"）虽然直观，但其效果受制于设计者的经验，且对不同任务、不同数据分布的适应性有限。更重要的是，对于细粒度分类这样的复杂任务，手工提示词难以精准表达品种间的细微差异，导致分类准确率和鲁棒性不足。

**前沿进展**：（1）**提示学习（Prompt Learning）**：Zhou等人提出的CoOp（Context Optimization）方法创新地将提示词中的上下文词汇建模为可学习的连续向量，通过少样本学习端到端优化这些向量，避免了手工设计的低效性。实验表明，仅用1-2张标注图像，CoOp就能超越精心调整的手工提示词，在16张样本时平均性能提升17%以上。（2）**条件提示学习（Conditional Prompt Learning）**：Zhou等人进一步提出CoCoOp，通过学习一个轻量级神经网络为每张图像生成条件动态提示，相比CoOp的静态提示更好地适应图像多样性和类别分布偏移，大幅提升了泛化性能。（3）**多模态提示优化**：最新的研究（如Choi等，2025）将提示优化扩展到多模态空间，同时优化文本和非文本（如图像）提示，采用贝叶斯优化策略选择性能最优的提示组合，这为构建更强大的多模态系统奠定了基础。

### 1.3 多模态模型在细粒度分类中的应用现状

多模态学习结合了图像视觉特征和文本语义信息，为解决细粒度分类问题提供了新的视角。当前的研究表明：（1）**单模态局限性**：基于纯卷积网络的方法虽然在大规模数据上表现良好，但对于细粒度任务，其学习到的特征仍倾向于捕捉高级语义特征（如颜色、整体轮廓），而对品种特有的局部特征（如耳朵形状、毛色纹理）的刻画能力有限。例如，在120个狗品种的Stanford Dogs数据集上，单一CNN模型的准确率通常在80%左右；即使结合多个CNN模型和SVM分类器，当前最好的非提示学习方法也仅能达到95.24%的准确率，且对某些相似品种（如英国猎犬与比格犬）的误分率仍超过30%。（2）**多模态优势**：视觉语言模型通过文本描述为视觉识别提供了额外的语义约束。例如，对于"金毛巡回犬"，可以用文本提示词描述"长金色毛发、友好面容、中等体型"，这样模型就能同时利用视觉特征和语义属性进行判断，显著提升细粒度区分能力。（3）**现有方法的不足**：尽管CLIP等VLP模型在零样本场景下表现优异，但现有的提示词优化方法（如CoOp）仍存在两个关键问题：一是提示词的泛化性不足——对训练集中出现的基础类别优化的提示在处理新类别或不同分布的数据时性能下降明显；二是缺乏动态调整机制——使用固定的学习提示词难以适应不同样本的多样性，特别是在环境干扰（光照变化、背景复杂、姿态多变）下的鲁棒性有限。

### 1.4 国内外研究差距与选题的紧迫性

（1）**国际前沿进展**：IEEE CVPR、IJCAI等国际顶级会议和IJCV、IEEE TPAMI等期刊上，大量文献聚焦提示学习和多模态适应（Gu等2023的系统调查, Zhou等2022的CoOp/CoCoOp, Choi等2025的多模态优化MPO）。但这些工作大多在通用分类基准（如ImageNet、Caltech-101）或特定领域（如医学影像）上验证，对于细粒度宠物品种分类这一具体应用场景的研究相对缺乏。（2）**国内研究现状**：国内关于细粒度猫狗分类的论文主要集中在传统CNN特征提取和迁移学习（如VGG、ResNet的微调），鲜少涉及新兴的视觉语言模型和提示学习技术的应用。（3）**关键技术缺口**：如何在提示词优化的框架内，设计专门针对细粒度品种分类的动态调整机制，使提示词能根据样本的视觉特征和背景条件自适应生成，从而既保证准确率提升，又保证泛化性能——这是一个亟待解决的问题。

### 1.5 本研究的创新意义

本研究的创新点在于：（1）**集成创新**：将最新的条件提示学习（CoCoOp）和多模态优化思想整合到细粒度猫狗分类框架中，形成"图像-文本联合表示+自适应动态提示"的新架构；（2）**方法创新**：设计一个自适应提示词生成算法，能根据输入样本的视觉特征和品种属性动态调整提示词，增强模型对相似品种的区分能力；（3）**应用创新**：针对猫狗品种识别这一具体场景，优化超参数和提示词模板，验证方法在真实应用中的有效性；（4）**可视化创新**：开发交互式演示界面，使得分类过程和决策依据可被用户直观理解，提升系统可信度。这些创新有望推进细粒度视觉识别在多模态框架下的理论和应用研究。

## 二、研究的基本内容，拟解决的主要问题

### 2.1 核心研究问题的界定

本研究的核心问题可表述为：**如何通过自适应提示词优化策略，增强基于多模态模型的细粒度猫狗分类的准确率和泛化能力？** 具体而言，研究需要解决以下四个子问题：

**问题1：细粒度品种特征的多模态表征**  
细粒度猫狗品种的区别往往体现在毛色、耳朵形状、眼睛大小等局部特征上。如何在VLP模型的多模态空间中精准表征这些细粒度差异？如何设计提示词，使其既能描述全局的品种属性（如体型、气质），又能准确刻画局部的判别特征？

**问题2：动态提示词的自适应生成机制**  
当前的提示学习方法（如CoOp）为每个类别学习一个固定的提示向量。但对于细粒度分类，同一品种的样本在不同拍摄环境下存在显著差异。如何设计一个动态提示词生成网络，根据输入图像的视觉内容实时调整提示词，使其既适应样本的多样性，又保持对品种特征的准确刻画？

**问题3：提示词的泛化性与鲁棒性**  
当前方法在基础训练类别上优化的提示容易过拟合，在新类别或分布外数据上性能下降。如何在优化提示词时引入正则化或对抗机制，增强提示对分布偏移和环境干扰（光照变化、背景复杂、遮挡）的鲁棒性？

**问题4：多模态信息的有效融合**  
如何在提示词优化过程中有效融合视觉特征（来自CLIP的图像编码器）和文本语义（来自提示词和类别描述），避免单一模态的信息浪费，实现真正的"视觉-语义互补"？

### 2.2 研究的基本内容

本研究分为四个层次的内容：

**（1）理论层：多模态细粒度分类框架的构建**

设计一个统一的细粒度猫狗分类框架，将提示学习与多模态表示相结合。框架主要组成部分包括：
- **冻结的视觉语言模型**：采用CLIP作为骨干，其图像编码器I_enc和文本编码器T_enc均保持预训练参数不变，以保证可迁移性；
- **可学习提示生成器**：设计一个条件提示生成网络P_gen，它将输入图像的视觉特征作为条件，输出动态的提示词向量p_dynamic，使提示词能适应每个样本的独特特征；
- **多模态融合模块**：在提示优化过程中，将视觉特征和文本语义通过注意力机制进行融合，增强品种特征的刻画能力。

形式化表述为：
- 给定输入图像x和类别集合C，传统方法计算相似度为：s_c = I_enc(x) · T_enc("a photo of" + class_name)
- 本研究提出的动态提示方法为：s_c = I_enc(x) · T_enc(p_dynamic(I_enc(x)) + class_description_c)
其中p_dynamic(·)是条件提示生成器，class_description_c是第c类品种的文本描述。

**（2）算法层：自适应动态提示词优化算法的设计**

主要创新算法包括：

*a) 条件提示词生成网络（CPGN, Conditional Prompt Generation Network）*
- 输入：图像的视觉特征f_vis = I_enc(x) ∈ R^d，其中d通常为512或768维（取决于CLIP版本）；
- 网络结构：轻量级多层感知机（MLP），包含2-3个全连接层，使用ReLU激活，参数数量控制在100K以内，以避免过度拟合；
- 输出：动态提示向量p_dynamic ∈ R^(L×d)，其中L是提示词的长度（通常4-8个词），每个位置都是d维的连续向量；
- 优化目标：最小化分类交叉熵损失与正则项的加权和：L_total = L_ce + λ₁·L_reg + λ₂·L_consistency
  其中L_ce是分类交叉熵，L_reg是对提示向量的L2正则化（防止过大偏离初始化），L_consistency是类内一致性约束（同一品种的不同样本生成的提示应相近）。

*b) 自适应学习率调度*
- 采用余弦退火学习率（Cosine Annealing LR），在训练早期使用较高的学习率快速优化提示，后期逐渐降低以稳定收敛；
- 对于少样本场景（如仅有1-5张样本），使用更小的学习率和更多的正则化，防止过拟合。

*c) 鲁棒性增强机制*
- **数据增强**：在训练时对输入图像进行随机裁剪、旋转、颜色抖动等变换，促使生成网络学习不变于这些变换的提示；
- **对抗正则化**：引入小幅度的对抗扰动到图像输入，优化提示词使其对这些扰动的输出仍保持一致，增强鲁棒性；
- **分布外评估**：在验证集上测试当图像风格、亮度、背景发生显著变化时的性能衰减，作为鲁棒性指标。

**（3）实验层：多维度的性能验证**

实验设计分为以下部分：

*a) 数据集与基准*
- 主要数据集：Stanford Dogs（120个品种，~20,500张图像）和Oxford-IIIT Pets（37个宠物品种，~7,400张图像）；
- 评估指标：Top-1准确率、Top-5准确率、精准率、召回率、F1-score；
- 比较对象：
  - 传统CNN基准：VGG16/ResNet50/EfficientNet等，通过ImageNet预训练+微调；
  - 提示学习基准：CoOp、CoCoOp、最新的多模态提示优化方法（MPO）；
  - 单一VLP基准：直接使用CLIP进行零样本或手工提示分类。

*b) 不同场景下的性能评估*
- 全样本场景：使用所有训练样本优化提示，验证方法的性能上界；
- 少样本场景：每类仅使用1、2、4、8、16张样本，评估提示学习的数据效率；
- 分布外泛化：测试在不同光照、背景、姿态、品种变体（如狗的毛长品种vs短毛品种）上的性能；
- 跨数据集评估：在Stanford Dogs上训练的模型，评估其在Oxford-IIIT Pets上的零样本迁移性能。

*c) 消融实验*
- 逐步移除提示生成网络、一致性约束、对抗正则化等组件，定量评估各部分的贡献；
- 比较不同提示长度（4, 6, 8词）、不同生成网络容量对性能的影响；
- 分析在仅10%/30%/50%训练数据上的性能衰减曲线。

**（4）应用层：可视化演示系统的开发**

开发一个基于Flask/Django后端和PyTorch模型的Web应用或桌面应用（使用PyQt/Tkinter），包含以下功能：
- **图像上传与预处理**：用户可上传猫狗图像，系统自动进行预处理（调整大小、归一化等）；
- **分类与排名**：显示Top-5候选品种及其置信度，并用柱状图或热力图可视化；
- **特征可视化**：通过Grad-CAM或注意力机制可视化，展示模型关注的图像区域（耳朵、眼睛等细粒度特征）；
- **提示词展示**：动态展示为输入图像生成的提示词内容，让用户理解模型的推理依据；
- **对比分析**：允许用户比较不同提示方法（如静态提示vs动态提示）在同一样本上的效果差异；
- **鲁棒性演示**：用户可对输入图像应用不同的变换（旋转、调光、加噪），观察模型的鲁棒性。

### 2.3 预期的主要创新点

**理论创新**：  
提出了一个"样本-自适应提示"的新范式，扩展了当前固定提示学习的思路，使提示词能根据输入样本的视觉内容动态调整，这为细粒度分类和其他需要样本级别定制的任务提供了通用框架。

**方法创新**：  
设计了包含条件提示生成网络、一致性约束和对抗鲁棒正则化的完整优化算法，相比简单的参数拼接或模板替换，本方法能更系统地利用多模态信息并增强泛化性。

**实验创新**：  
在多个维度（全样本、少样本、分布外、跨数据集）的系统评估框架，提供了细粒度分类在多模态设置下性能的全面刻画，超越了仅在单一基准上的有限验证。

**应用创新**：  
将学术研究与实际应用相结合，开发的可视化系统使黑盒分类模型变为可解释的决策工具，具有潜在的商业价值和社会意义。

## 三、研究步骤、方法及措施

### 3.1 总体研究路线

本研究将按"理论设计→算法实现→实验验证→应用开发"的四个阶段递进展开，整体周期为12个月。以下为详细的时间规划和关键里程碑：

| 阶段 | 时间 | 主要任务 | 关键输出 |
|------|------|---------|---------|
| I    | 2026年1月-3月中旬 | 框架设计与实验准备 | 算法设计文档、环境配置、基准复现 |
| II   | 2026年3月中旬-4月中旬 | 核心算法开发与初步验证 | 动态提示生成器、小规模实验结果 |
| III  | 2026年4月中旬-4月底 | 全面实验与对比分析 | 完整的实验报告、性能对标数据 |
| IV   | 2026年5月-6月 | 系统集成与论文撰写 | 可视化系统、论文定稿、开源代码 |

### 3.2 第一阶段：框架设计与实验准备（2026.1-2026.3中旬）

**任务1：深入文献调研与理论基础**
- 系统阅读 Gu等(2023)关于提示工程的调查、Zhou等(2022)的CoOp/CoCoOp、Choi等(2025)的多模态优化MPO等核心论文，理解最新进展；
- 整理细粒度分类的经典方法（如基于部分的模型、双线性CNN等）与当前VLP方法的优劣对比；
- 梳理CLIP、ALIGN等VLP模型的技术细节，包括图像/文本编码器的架构、预训练策略等；
- 撰写详细的文献综述（不少于5000字），作为论文绪论的基础。

**任务2：数据集的处理与基准建立**
- 下载Stanford Dogs和Oxford-IIIT Pets数据集，进行数据清洗、验证集划分（通常80%训练+20%验证）；
- 对每个狗品种和猫品种手动编写5-10条属性描述（如"短毛、大耳朵、棕色眼睛"），形成品种属性库；
- 使用CLIP的预训练模型，对全部样本进行图像和文本编码，保存为NumPy数组或HDF5格式，以加速后续实验；
- 复现CoOp和CoCoOp在Stanford Dogs上的结果，建立性能基准（目标：CoOp ~80%，CoCoOp ~85%）。

**任务3：开发环境搭建与代码框架设计**
- 配置深度学习环境：Python 3.9+，PyTorch 2.0+，CLIP库，必要的数据处理库（PIL, NumPy, Scikit-learn）；
- 设计统一的代码框架：
  - `models/`目录：CLIP模型加载、条件提示生成网络、融合模块的实现；
  - `datasets/`目录：自定义数据加载器，支持不同的数据增强策略；
  - `train.py`：统一的训练脚本，支持不同配置（提示方法、优化器、超参数）；
  - `evaluate.py`：评估脚本，计算多种指标；
  - `configs/`目录：YAML配置文件，管理所有超参数。
- 搭建实验管理框架（如使用Weights & Biases或MLflow），记录每次实验的参数、中间结果和最终指标。

### 3.3 第二阶段：核心算法开发与初步验证（2026.3中旬-4月中旬）

**任务4：条件提示生成网络（CPGN）的实现**

网络架构设计如下：
```
输入：图像特征 f_vis ∈ R^512 （来自CLIP的图像编码器）

网络结构：
  Layer 1: Linear(512, 256) + BatchNorm + ReLU
  Layer 2: Linear(256, 256) + BatchNorm + ReLU + Dropout(0.1)
  Layer 3: Linear(256, L×512) 其中L=4（提示词长度）

输出：动态提示向量 p_dynamic ∈ R^(4×512)
      （4个512维的向量，可与4个类别描述词进行对应）
```

实现细节：
- 参数初始化：使用Xavier初始化确保训练稳定性；
- 正则化：在第2层使用Dropout(0.1)防止过拟合；
- 批标准化：加速收敛并提升稳定性。

**任务5：优化算法与训练策略**

设计如下优化策略：
- **损失函数**：
  L_total = L_ce + λ₁·||p_dynamic||²₂ + λ₂·L_consistency
  
  其中：
  - L_ce 是交叉熵损失：L_ce = -1/N Σᵢ log(exp(sim(f_vis^i, p^i_c)) / Σₖ exp(sim(f_vis^i, p^i_k)))
  - L_consistency 促进同一类内不同样本的提示相近：L_consistency = 1/C Σ_c Var(p_dynamic for class c)
  - λ₁, λ₂为权衡系数，初始设为0.01和0.001；

- **优化器**：采用AdamW，初始学习率1e-4，使用余弦退火策略逐步降低；
- **批大小**：32（如内存不足可改为16）；
- **训练轮数**：100个epochs，使用EarlyStopping机制（验证损失连续20个epochs不改进则停止）。

**任务6：初步实验与算法迭代**

设计初步的全样本实验：
- 在Stanford Dogs的120个品种上使用所有训练图像（16000+张）进行训练；
- 目标：动态提示方法（DPGN）的准确率超过CoCoOp至少3个百分点；
- 产出：初步实验报告，包括学习曲线、收敛速度、不同超参数的影响分析；
- 问题排查：若效果未达预期，进行详细的消融分析（如移除一致性约束、改变提示长度等），迭代改进算法。

### 3.6 关键技术措施与风险应对

**数据不足的应对**：
- 如果在细粒度属性标注时样本不足，可利用大模型（如GPT-4）自动生成品种属性描述，再由人工验证；
- 采用数据增强（旋转、颜色变换、MixUp等）扩充训练集。

**收敛困难的应对**：
- 若提示生成网络难以收敛，可减小提示长度（从4改为3）、降低学习率、增加正则化强度；
- 尝试预训练提示生成网络（先在大规模数据如ImageNet上预训练，再迁移到细粒度任务）。

**计算资源限制的应对**：
- 使用梯度累积和混合精度（Mixed Precision）训练，减少显存占用；
- 若单GPU内存不足，可采用数据并行分布式训练（DistributedDataParallel）。

**模型部署的优化**：
- 使用ONNX或TorchScript将PyTorch模型转换为标准格式，便于跨框架部署；
- 考虑模型蒸馏，将复杂模型压缩为更小的学生模型，加快推理速度。
